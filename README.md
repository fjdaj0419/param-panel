# Param Panel · 参数调节面板

> 当 AI 要问"你想要多强 / 几成 / 什么风格"时，别让它打一行字问你——让它弹一个面板：**先勾选要调的参数，再拖动进度条或输入精确数值，右边产品实时变**，你自己挑出最舒服的那个，再让它继续干活。

一个 Agent Skill（适用于 WorkBuddy、Claude Code 等支持 `SKILL.md` 的环境）。

---

## 它解决什么问题

让 AI 做海报、落地页、界面、图表时，总有些参数得你来定：圆角多大、配色多鲜艳、要不要徽章、价格区间怎么划。

传统做法是 AI 反问你一句"你想要什么风格？"，然后你**凭空猜一个词**，它做出来，你不满意，再改。来回三五轮，而且根本不知道那个词长什么样。

这个技能把"文字反问"换成**所见即所得的调节面板**：

1. **先选参数**——候选参数勾选即可，也能自己输入一个要调的
2. **再调数值**——每个参数配**可拖动进度条 + 数字输入框**，拖动找感觉、输入精确值，两者双向同步
3. **全程对照**——"当前值 → 调整后值 → 变化量"逐项显示，另有变更汇总表
4. **实时预览**——右侧产品卡片随任一参数变化即时重绘
5. **确认回传**——点确认，所有值结构化写回对话，AI 立即继续生成

**你不是在猜数字，你是在看着成品挑参数。**

## 界面长什么样

```
第一步 · 选参数（可勾选，也可自己加）
  [✓] 配色风格 当前 极简灰   [✓] 圆角大小 当前 14px   [ ] 元素间距
  [✓] 价格下限 当前 ¥100     [✓] 价格上限 当前 ¥900   [+] 自定义参数名... [添加参数]

第二步 · 调数值（拖动进度条或手动输入）     │ 变更对照
  圆角大小     当前 14px · 调整后 22px +8px   │  圆角  14px → 22px (+8px)
  ●━━━━━━○ [ 22 ]                            │  价格  ¥100 → ¥300 (+¥200)
  配色风格     当前 极简灰 · 调整后 珊瑚       │
  [极简灰][夜间][珊瑚]                        │ 最终效果预览
  价格下限     当前 ¥100 · 调整后 ¥300        │  ┌──────────────┐
  ●━━━○──── [ 300 ]                          │  │ SUMMER 2026  │
                                              │  │  夏日特惠     │
  [↺ 重置推荐]        [确认，就按这个做 ↗]     │  └──────────────┘
```

## 交互能力

| 能力 | 说明 |
|---|---|
| 可拖动进度条 | 数值型参数用 `<input type=range>`，拖动即时联动预览 |
| 手动精确输入 | 每个拖动条旁配数字输入框，输入后拖动条同步定位 |
| 自定义参数 | 第一步输入任意参数名，自动生成一个带拖动条的新参数 |
| 分段档位 | 离散选项（低/中/高、配色风格）用一排高亮按钮 |
| 开关 | 二选一（要不要徽章、阴影）用点击切换的开关 |
| 变更对照 | 逐项显示 当前值 / 调整后值 / 变化量，另有汇总表 |
| 重置推荐 | 一键把所有参数弹回推荐值，预览同步还原 |
| 确认回传 | `sendPrompt()` 把全部最终值结构化写回对话 |

## 安装

### WorkBuddy

```
设置 → 技能 → 添加技能 → 上传技能 → 选择 param-panel.skill
```

或者直接把本仓库克隆到技能目录：

```
git clone https://github.com/fjdaj0419/param-panel.git ~/.workbuddy/skills/param-panel
```

### Claude Code / 其他支持 Agent Skills 的环境

```
git clone https://github.com/fjdaj0419/param-panel.git ~/.claude/skills/param-panel
```

本仓库是标准 Agent Skill 结构：根目录 `SKILL.md`（YAML frontmatter 只含 `name` 和 `description`）+ `assets/`，没有绑定任何平台的私有字段，所以换环境照样能用。

### 手动

把 `SKILL.md` 和 `assets/` 放进任意 `skills/param-panel/` 目录即可。

## 使用

### 自动触发

装上就生效，正常说话就行：

- "帮我做个落地页，动效强度你来定"
- "海报配色给几个方案我自己挑"
- "价格区间你看着定"

命中这几类语义时它自己会弹面板：**程度、百分比、比例、多强、多大、档位、强度、配色、风格、调一下、你来定、调到合适、最佳状态、看看效果、对比一下**。

### 手动点名

在输入框打 `/`，从列表里选 `param-panel`，再写需求：

```
/param-panel 帮我做活动页，配色和圆角我来调
```

### 它不会乱弹

必须同时满足四条才触发：正在生成产品 / 缺一个可调参数 / 你没给明确数值 / **能做出可视化预览**。

最后一条是硬门槛：如果只能给你一句文字描述、产品看不出变化，它宁可直接文字问你，也不弹一个没用的面板。

## 技术实现（这段是本项目的核心）

面板骨架是**静态 HTML + 脚本增强**：

- `<div class="pp">` 的容器结构和各区块（选参数、调节、对照、预览、操作）第一帧就在 HTML 里
- 末尾 `<script>` 负责把 `CONFIG.params` 渲染成控件、绑定拖动/输入/勾选事件、更新对照表与预览、调 `sendPrompt()` 回传
- 预览是**数据驱动**的：`CONFIG.preview(values)` 只返回一个数据对象（色值、圆角、徽章显隐、进度条位置……），模板内置渲染把它套进产品卡片——模型一行 HTML 都不用写

为什么这么设计？因为踩过坑：

1. **早期版本让模型手写 HTML 字符串拼接**（一个函数 30+ 处 `+`、60+ 个引号），改写时极易写坏引号导致整段脚本语法错误、面板全空白。改为数据驱动后，模型只填数据。
2. **渲染器禁止 `<form>`**，会直接报错拒绝加载，所以用 `<div>` 当容器。
3. **辅助文字 `<h2 class="sr-only">` 必须配隐藏样式**，否则会显示成大标题。
4. **显示数值一律圆整**（`Math.round`），单位位置区分前后缀（px 后缀、¥ 前缀）。

### 改模板只需动 `CONFIG` 一处

| 改什么 | 怎么改 |
|---|---|
| 文案 | `CONFIG.title` / `sub` / `kicker` / `titleText` / `desc` / `chips` / `buttonText` |
| 参数 | `CONFIG.params`——每个对象填 `id/name/type/current/recommended/on`，数值型再填 `min/max/step/unit` |
| 配色 | `CONFIG.preview` 里的 `T` 映射表（档位名 → 一组色值） |
| 卡片内容 | 改 `.pcard` 内部结构，但保留 `badge/kc/tt/ds/cs/ci/bw/br/ft/pl/bt` 这些 class——联动全靠它们 |

`init()` 及以下所有渲染函数是通用的，**不要重写**。

## 回传格式

用户点确认后，每个勾选的参数一行写回对话：

```
已确认：[参数名] = [调整后值]（当前 [当前值]，变化 [±值]）。请据此继续生成。
```

模型解析后一句话确认，立即继续原本的生成任务，不再反问。
